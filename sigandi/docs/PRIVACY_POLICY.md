# Privacy Policy

Effective Date: May 1, 2026
Product: Sistem Garis Akta Notaris Digital
Provider: Radina.net

## 1. Data Processed by the Application
The application primarily processes:
- Input documents selected by the user (PDF/DOCX converted to PDF).
- User-edited line metadata and project state.
- License activation data (license key, machine fingerprint, activation result, expiry, customer metadata if provided).

## 2. Local Processing
Document rendering, line detection, and PDF output are performed locally on the user device.

## 3. Network Usage
Internet is required for license activation/verification flow (as configured by license endpoint).
No cloud upload of document content is intended by default application flow unless explicitly configured by the customer.

## 4. Data Storage
The application stores local files such as:
- License file (`garis_editor_license.json` and/or user-local license path).
- Temporary files for printing, conversion, booklet preview, and compression.

Temporary files are managed by the app lifecycle and may persist if process termination is abnormal.

## 5. Data Retention
Retention of source documents and exported outputs is controlled by the user.
Users are responsible for deletion and archival policies in their environment.

## 6. Security
Reasonable efforts are made to protect license and runtime data; however, endpoint security (OS hardening, antivirus, access controls) remains the user/customer responsibility.

## 7. Third-Party Dependencies
Third-party libraries may process document bytes in memory/runtime.
Their behavior is governed by their own licenses and documentation.
