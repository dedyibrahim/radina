Provider: Radina.net

## 1. Support Channel
- Primary: WhatsApp 087724170145

## 2. Support Hours
- Monday to Friday: 09:00 - 17:00 WIB
- Outside business hours: best-effort response

## 3. Severity Levels
- Sev-1 (Critical): Application unusable for core workflow (open/edit/export).
- Sev-2 (High): Major feature degraded with no acceptable workaround.
- Sev-3 (Medium): Partial issue with workaround available.
- Sev-4 (Low): Cosmetic issue, enhancement request, or documentation request.

## 4. Initial Response Target
- Sev-1: within 4 business hours
- Sev-2: within 8 business hours
- Sev-3: within 2 business days
- Sev-4: within 5 business days

## 5. Resolution Target
Resolution target depends on issue complexity, reproducibility, and dependency constraints.
Radina.net will provide workaround-first remediation where possible.

## 6. Scope Included
- Installation/build guidance for official release artifacts
- License activation issue handling
- Functional bug triage for supported versions

## 7. Out of Scope
- Custom feature development not agreed in writing
- Infrastructure/network issues outside the application boundary
- User-side data loss caused by unmanaged backup practices

## 8. Prerequisites for Ticket Handling
Please provide:
- App version
- OS version
- Reproduction steps
- Screenshot/video (if possible)
- Log/error message text

## 9. SLA Exclusions
SLA does not apply during:
- Force majeure events
- Third-party service outages
- Customer environment changes outside support baseline
